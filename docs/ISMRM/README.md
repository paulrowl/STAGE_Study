# ISMRM Conference Materials

This folder contains materials for the International Society for Magnetic Resonance in Medicine (ISMRM) conference submission.

## ISMRM Abstract Requirements

**Format:** Structured abstract
**Word limit:** Typically 750 words (verify current requirements)
**Structure:**
- Purpose/Hypothesis
- Methods
- Results
- Conclusions

**Submission deadlines:** Usually November for annual meeting (May)

## Data Source

All materials in this folder are based on the corrected STAGE Study analysis:
- **T1-weighted:** n=41 paired subjects
- **T2-weighted:** n=31 paired subjects
- **SWI:** n=38 paired subjects
- **Complete data:** 30 subjects with all 3 modalities

## Key Findings for ISMRM Audience

1. **T2 STAGE:** Significantly reduced tissue contrast (-17.6%, p<0.001, d=-1.01)
2. **SWI STAGE:** Preserved tissue contrast (p=0.679) despite intensity increases
3. **T1 STAGE:** Protocol equivalence with strong correlations (r>0.86, p<0.001)
